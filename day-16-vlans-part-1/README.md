# CCNA Labs

Cisco Packet Tracer labs I completed while studying for the Cisco CCNA (Cisco Certified Network Associate) exam. Each folder has a topology diagram, the configuration of every router and switch, a write up of what I did, and the original Packet Tracer file.

I'm a Computer Information Systems senior at Colorado Mesa University and hold the CompTIA Security+ certification.

## Labs

| Lab | Topics |
|---|---|
| [Day 4: Basic Device Security](day-04-basic-device-security) | Hostnames, enable secret, password encryption |
| [Day 6: Ethernet LAN Switching](day-06-ethernet-lan-switching) | MAC address learning, flooding, ARP |
| [Day 8: IPv4 Addressing](day-08-ipv4-addressing) | Class A, B, and C networks, interface addressing |
| [Day 9: Interface Configuration](day-09-interface-configuration) | Speed and duplex, descriptions, shutting down unused ports |
| [Day 11: Troubleshooting Static Routes](day-11-troubleshooting-static-routes) | Static routing, next hop errors, fixing a broken path |
| [Day 12: Life of a Packet](day-12-life-of-a-packet) | Frame rewriting at each hop, end to end packet flow |
| [Day 15: VLSM](day-15-vlsm) | Variable Length Subnet Masking, subnet planning, static routes |
| [Day 16: VLANs (Part 1)](day-16-vlans-part-1) | VLAN creation, access ports, routing between VLANs |

## Skills shown
Cisco IOS (Internetwork Operating System) configuration, IPv4 addressing and subnetting, static routing, switch operation, VLANs (Virtual Local Area Networks), device hardening, and step by step troubleshooting.

## How to view
- `topology.png` and `README.md` in each folder show the network and what I configured
- `configs/` holds each device's running configuration as plain text
- The `.pkt` files open in Cisco Packet Tracer 9.0 or newer
